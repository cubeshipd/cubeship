## Fixed

**Templates can configure app networking.** A template can declare an app's
internal ports and HTTP readiness checks, including the port each check uses.
The catalog validates these settings and installations apply them on create
and update. If an update fails, rollback restores the app's prior networking
configuration.

The Jian template now checks the gateway at `/health` on port `4310` and the
panel at `/web/health` on port `3000`.
