## Added

**GitLab and Gitea.** Connect GitLab, including self-hosted instances, and Gitea from Git Providers with an API token. Their repositories and branches appear in Build Source alongside GitHub and Bitbucket. Each connection has a webhook secret for deploy on push.

**Git deployment details.** Deployments from source repositories record the resolved commit and branch, including manually started builds, and show the commit in deployment history. Image-based deployments continue to show the image.

## Fixed

**Registry disk reclamation.** Garbage collection runs in a temporary container while the serving registry is stopped, then restarts the registry. The dialog keeps long errors within its width.

**Git provider return flow.** Successful GitHub and Bitbucket connections return to Git Providers instead of stopping on a separate connected page.

## Changed

**Dashboard controls.** Filters across resource pages follow a consistent layout. Components from all nodes share one table with a node filter and row actions for logs and shell. Settings are organized on one page, and template installation uses a full-width DNS provider selector.

**Appearance and accounts.** Choose a light or dark base and an accent independently. Account controls, profile pictures, Users, and Audit Log filters have been simplified and aligned with the dashboard.

**Updates and release notes.** Release notes have their own page. The update dialog and progress display use the current dashboard components; the page reloads after a completed update.

## Upgrade notes

Select 0.12.0-rc.11 from an instance with prereleases enabled, or name this version when installing. Migration 00070 stores GitLab and Gitea connections; existing GitHub and Bitbucket connections are unchanged. Configure each repository's webhook with the URL and secret shown in Git Providers to enable deploy on push. This candidate does not move the stable latest release or image tags.
