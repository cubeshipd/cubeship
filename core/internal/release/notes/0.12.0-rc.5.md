## Added

**Configured health checks are real deploy gates.** An app can check an HTTP
path or a TCP port before its new container replaces the old one. The probe
uses the app's configured target and routed port, so a process that is running
but not ready never receives traffic.

**Bitbucket connections finish in the dashboard.** After authorizing a
Bitbucket account, the dashboard now takes the connection through its
dedicated completion screen and keeps repository and branch selection in the
same flow.

## Fixed

**Unhealthy containers no longer become the active deploy.** HTTP and TCP
probe failures keep the existing container serving and report the failed
deploy instead of swapping in a container that cannot answer.

## Upgrade notes

Update normally from the dashboard or CLI. No database migrations.
