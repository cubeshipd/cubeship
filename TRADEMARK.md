# The name

**"Cubeship", the logo and the look of the dashboard are not granted by
[LICENSE](LICENSE).** Apache-2.0 section 6 excludes trademarks on purpose:
the code is yours to use and the name stays ours. This file is what that
means in practice.

You do not need permission to:

- say your project runs on Cubeship, or works with it;
- write about it, review it, compare it to something else, or teach it;
- keep the name where it already is when you build the code unchanged —
  a fork you run on your own machine is nobody's business but yours.

You do need permission to:

- publish a modified build under the name Cubeship, or under a name close
  enough to be taken for it;
- use the name or the logo for your own product, service or company, or in
  a way that suggests this project endorses either.

**A public fork gets its own name.** Change the name in the dashboard, in
the image references and in the installer, so that whoever installs it
knows whose build they are running and who to ask when it breaks. That is
the whole of the rule, and it is the reason for it: a Cubeship that is not
this one, answering at the same name, is a support burden landing on the
wrong person and a reputation moving without its owner.

Asking is fine, and the answer is often yes —
[open an issue](https://github.com/cubeshipd/cubeship/issues).
