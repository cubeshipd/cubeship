---
title: Upgrading
description: Run the installer again. Nothing under the data directory is touched.
---

Run the installer again. It pulls the newest release and replaces the
containers; nothing under the data directory is touched.

```bash
curl -fsSL https://cubeship.dev/install.sh | sh
```

The dashboard shows you what changed the next time you open it. What is
in each release is in the
[changelog](https://github.com/cubeshipd/cubeship/blob/master/CHANGELOG.md).
